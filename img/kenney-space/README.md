# Kenney Space Shooter Extension sprites

Rocket, launch bay, exhaust and smoke sprites used by the Resume section's launch
animation in `index.html`. Picked from the 2x sprites of Kenney's
[Space Shooter Extension](https://kenney.nl/assets/space-shooter-extension) pack
and renamed for readability (for example `nose.png` is `spaceRocketParts_010.png`).
